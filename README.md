# PicGo 图床

用 PicGo 上传的个人图床，存放博客、笔记和其他仓库 README 引用的图片，通过 jsDelivr CDN 访问：

```
https://cdn.jsdelivr.net/gh/chen0495/newpicgo/<路径>
```

## 目录

| 目录 | 内容 |
| --- | --- |
| `img/` | 2020–2021 年的图片（约 1500 张） |
| `img2021/` | 2021 年图片 |
| `img2022/` | 2022 年及以后的图片 |

> 多个仓库的 README（如 `pio-fpn-parameter-optimization`、`jsu-grade-crawler`、`cs408-data-structure-notes`）通过上面的 CDN 地址引用本仓库图片。该地址指向 **GitHub** 上的 `chen0495/newpicgo`，因此 GitHub 上的原仓库不能删除或改名。
